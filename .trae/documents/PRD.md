# 粵歌仔（YueGeZai）产品需求文档

## 1. 产品概述
一款复古 8-bit 像素风的粤语歌曲猜歌休闲网页应用，基于 iTunes Search API 官方 30 秒预览音源，复刻参考图「粵歌仔」核心玩法；面向粤语流行音乐爱好者与碎片化娱乐移动端用户，主打零服务器成本、合规可用的轻量游戏体验。

- 部署：Cloudflare Pages（静态页面 + Pages Functions 代理）
- 核心价值：合规官方音源 + 复古像素美学 + 单人闯关 + 等级 XP 成长系统

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通玩家 | 无需注册，localStorage 本地存储 | 单人闯关、查看等级、使用道具 |

### 2.2 功能模块
1. **首页（主菜单）**：等级徽章、升级引导、品牌展示、角色展示、模式选择入口
2. **等级详情页**：等级徽章、经验进度条、准确率/游戏次数统计、开始游戏入口
3. **答题核心页**：音频播放、4 选项答题、道具系统、回合进度
4. **本局成绩页**：得分展示、答题详情列表（对错区分）、继续按钮
5. **最终结算页**：评价横幅、本局 XP、升级进度更新、再玩一次/主页按钮

## 3. 核心流程

### 3.1 单人模式完整链路
用户进入首页 → 查看当前等级与升级所需 XP → 点击「單人模式」→ 等级详情页查看历史准确率/游戏次数 → 点击「開始遊戲」→ 后端代理拉取题目并加载第一题音频 → 用户播放音频选择答案 → 即时反馈对错 → 自动进入下一题 → 完成 10 题 → 本局成绩页 → 点击「繼續」→ 最终结算页发放 XP、更新等级 → 「再玩一次」或「主頁」。

### 3.3 题目生成规则
- 通过歌手关键词（郑秀文、陈奕迅、张敬轩、Dear Jane 等）批量拉取歌曲池
- 单题：从歌曲池随机抽 1 首作为正确答案，再抽 3 首作为干扰选项，4 选项打乱顺序分配 A/B/C/D
- 单局一次性生成 10 道不重复题目，前端本地缓存

## 4. 用户界面设计

### 4.1 设计风格
- **整体风格**：8-bit 复古像素风，所有按钮/图标/文字带像素描边与块状质感
- **主色**：深紫到深蓝渐变背景（#1a0b2e → #0d1b3e），叠加像素网格暗纹
- **按钮撞色**：粉紫 #d946ef（单人模式）、浅蓝 #38bdf8（派对模式）、橙黄 #f59e0b（开始/继续）、黄色 #fbbf24（选项）、绿色 #22c55e（正确）、红色 #ef4444（错误/进度填充）
- **文字**：白色像素字体（Press Start 2P / DotGothic16），标题带深色像素描边
- **装饰**：音符、CD、磁带、耳机、麦克风、星星、爱心像素图标散点分布
- **动效**：按钮按压反馈、答对/升级闪光动效、整体节奏轻快复古

### 4.2 页面设计概览

### 4.3 响应式设计
- 移动端优先（碎片化娱乐场景），最大宽度 480px 居中布局
- 桌面端居中卡片式布局，背景展示完整装饰
- 触控优化：按钮最小 44px 触控目标，按压反馈动效

## 5. 数据与存储

### 5.1 本地数据（localStorage）
| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| level | number | 1 | 当前等级 |
| currentXP | number | 0 | 当前累计经验值 |
| levelUpXP | number | 10 | 当前等级升级所需总 XP（每级递增） |
| totalGames | number | 0 | 累计游戏局数 |
| totalCorrect | number | 0 | 累计答对题目数 |
| items.fiftyFifty | number | 3 | 50/50 道具数量 |
| items.replay | number | 3 | 重播道具数量 |

### 5.2 经验规则
- 每答对 1 题获得 1 XP
- 单局结算时统一发放本局总 XP
- 达到升级阈值自动升级，溢出 XP 累计到下一级

## 6. 版权与合规
- 页面底部固定标注：`Preview provided courtesy of Apple Music`
- 仅使用官方 30 秒预览片段，不提供完整歌曲播放/下载
- 非商用娱乐用途，不收费、不接广告

## 7. 开发优先级
1. **第一阶段（核心可用）**：首页 + 答题页 + 结算页 + Cloudflare Functions 代理 + 随机题目 + 音频播放 + 本地 XP 存储
2. **第二阶段（体验完善）**：道具系统（50/50、重播）+ 等级详情页 + 准确率统计 + 像素动效
3. **第三阶段（扩展功能）**：派对模式多人房间 + 难度分级 + 分享功能
